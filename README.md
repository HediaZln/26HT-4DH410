# 26HT-4DH410

Appendices: lexicons and documentation

This repository contains the appendices of a mini-project on Émile Zola's La Bête humaine (1890) and how Lison, the locomotive, relates to the women of the novel. It includes 11 keywords analyzed, six thematic lexicons (affection, body, desire, machine, possession, violence), a documentation file giving for each lemma its English translation, category, level (core or extended), corpus frequency and source (lexicons_documentation_en.csv), and a file listing the rejected or excluded lemmas with the reason (lexicons_rejected_en.csv). The lemmas were drawn from the French NRC Emotion Lexicon (Mohammad & Turney, 2010), reviewed manually, and completed with seed words and frequent lemmas from the novel; the lexicons were also compared with FEEL (Abdaoui et al., 2017). The novels themselves are not included: they are available on Project Gutenberg (La Bête humaine, ebook no. 5154).
